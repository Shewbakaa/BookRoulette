# BookRoulette

A phone-first PWA: spin a 3D book carousel roulette to pick your next read.

## Local development

```bash
npm install
npm run dev
```

Open http://localhost:5173/BookRoulette/?demo

## Tests

```bash
npx vitest run
```

## Deploy

Deployed to GitHub Pages by `.github/workflows/deploy.yml` on push to `main`.
In the repo: Settings -> Pages -> Source: GitHub Actions.

## iPhone tip

Open the site in Safari -> Share -> Add to Home Screen. The camera (barcode scan) needs https.
